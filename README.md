# DataCenter Atlas

> 기후·전력·재생에너지·통신 인프라를 종합해 **전 세계 데이터센터 입지 적합도**를 분석하고,
> 최적 설치 지역을 추천하는 웹 애플리케이션

**심화 탐구 주제**
데이터센터는 세계 어디에 설치하는 것이 가장 효율적이며, 현재 운영 중인 데이터센터의 입지는 얼마나 적합한가?

## 주요 기능

### 지도
- 전 세계 **184개 데이터센터**(78개 사업자) 위치 표시
- 25km 이내 지점은 하나로 묶어 표시하고, 클릭하면 목록에서 개별 선택
- 적합도 항목별 **색상 히트맵** (종합·기후·전력·재생에너지·수자원·전력망·통신·재해·토지)
- 지도를 **길게 누르면** 그 지점의 입지 적합도를 즉석 평가 (실제 기상 관측값 조회)
- 국가를 클릭하면 지표 카드 표시, 한국어 국가명 라벨

### 분석
- 8개 항목 가중합으로 100점 만점 적합도 산출
- 목적별 프리셋 8종: AI 학습용 / GPU 클러스터 / HPC / 클라우드 / 친환경 / 비용 절감 / 초저지연 / 균형
- 가중치 직접 조절 → 순위·지도 색상·마커가 실시간 반영
- **지표 중복(상관) 보정** — 상관계수 0.5 초과분만큼 유효 가중치를 낮춤
- AI 분석 의견: 장점 / 단점 / 실제 사례 / 추천 여부 4구획
- 항목별 점수 근거와 출처 표시, 총점 계산 과정 시각화

### 시뮬레이션
- IT 부하(5~500MW)·GPU 비중·냉각 방식(공랭/수냉/외기/액침)을 조절하면
  PUE·연간 전력·전기요금·탄소배출·냉각수·건설비 자동 계산
- **기후 시나리오**: 현재 / 2035 / 2050 / 2080 / 2100 — 위도별 온난화 증폭 반영
- 최대 5개국 비교(레이더 차트·표·순위 변화 그래프)
- 보고서 자동 생성 (Markdown · PDF · CSV) — 탐구 보고서 서식 별도 제공

## 분석 방법

### 평가 항목과 기본 가중치

| 항목 | 가중치 | 자료 성격 |
|---|---:|---|
| 기후·냉각 | 18% | **실측** — 대표 지점 연평균 기온(°C) 정규화 |
| 전력 비용 | 18% | 공개 통계 기반 배정값 |
| 재생에너지 | 14% | 공개 통계 기반 배정값 |
| 전력망 안정성 | 14% | 공개 통계 기반 배정값 |
| 냉각 수자원 | 9% | 공개 통계 기반 배정값 |
| 인터넷 인프라 | 9% | 공개 통계 기반 배정값 |
| 재해 위험 | 9% | 공개 통계 기반 배정값 |
| 토지 비용 | 9% | 공개 통계 기반 배정값 |

총점 = Σ(항목 점수 × 가중치) ÷ Σ(가중치)

위 표는 기본값 기준입니다. 분석 탭의 "공개 데이터 불러오기"를 누르면 기후·재생에너지·전력망 안정성·
냉각 수자원·인터넷 인프라·토지 비용 6개는 World Bank·Open-Meteo 실측값으로 바뀝니다. 전력 비용·재해
위험 2개는 무료로 쓸 수 있는 공개 API가 없어 추정값으로 남습니다.

탄소배출 계산에는 재생에너지 비율이 아니라 **실제 계통 탄소집약도(gCO₂/kWh)** 를 사용합니다.
재생에너지 비율만으로 추정하면 원자력 비중이 큰 프랑스·스웨덴·한국이 크게 왜곡되기 때문입니다.

### 기후 시나리오

IPCC 중간 경로(SSP2-4.5)를 참고해 2035년 +1.1℃, 2050년 +2.2℃를 가정하되,
**위도별 증폭 계수**를 적용합니다.

| 지역 | 증폭 배율 | 2050년 상승폭 |
|---|---:|---:|
| 북극권 (72°) | ×1.94 | +4.3℃ |
| 고위도 (64°) | ×1.67 | +3.7℃ |
| 중위도 (37°) | ×1.03 | +2.3℃ |
| 열대 (0°) | ×0.75 | +1.7℃ |

물 부족은 아열대 건조대(20~35°)에서, 기상재해는 태풍대(저·중위도)에서 더 크게 악화되도록 계산합니다.

## 한계

이 프로젝트는 **학습용 모델**입니다. 실제 투자 판단에 사용할 수 없습니다.

- 기본값은 8개 항목 모두 공개 통계를 참고해 0~100으로 배정한 값이며, 원자료를 그대로
  정규화한 것이 아닙니다. "공개 데이터 불러오기"를 누르면 6개(기후·재생에너지·전력망 안정성·
  냉각 수자원·인터넷 인프라·토지 비용)는 **실측**으로 바뀝니다. 전력 비용·재해 위험 2개는
  무료 API가 없어 계속 추정값입니다.
- 지도 색상은 **국가 단위 근사치**입니다. 같은 나라 안에서 지점을 바꿔도 기온 외에는 차이가 작습니다.
- 데이터센터 126곳은 대표 캠퍼스만 수록한 것으로, 전 세계 약 11,000개 중 일부입니다.
- 시뮬레이터의 PUE·전력 단가는 점수에서 역산한 추정값입니다.

## 개발

소스는 `src/` 에 나뉘어 있고, 빌드하면 단일 HTML 이 만들어집니다.
결과물이 파일 하나라 서버 없이 `file://` 로도 열립니다.

```bash
node build.js      # src/ → index.html + dist/datacenter-atlas.html
node tests/run.js  # 브라우저 없이 전체 실행 + 자체 점검 23항목
```

```
src/
  00-helpers.js                  공용 헬퍼, 오류 핸들러
  data/countries-and-sites.js    국가·데이터센터 원자료      (31KB)
  core/state-and-scoring.js      상태·점수 계산·시나리오     (4.3KB)
  ui/tabs.js  map.js  modules.js  analysis.js
  tests/selftest.js              브라우저에서 도는 자체 점검
  boot.js                        초기화·배선
```

앱 주소 끝에 `?selftest` 를 붙이면 브라우저 콘솔에서도 점검이 실행됩니다.

### 작업 원칙

1. 수정 후 반드시 `node tests/run.js` — 구문은 맞는데 실행이 안 되는 상태를 잡아 줍니다.
2. 여러 곳에서 쓰는 함수는 `const f = () => {}` 대신 `function f() {}` (선언 순서 문제 방지).
3. 상태를 바꾼 뒤 렌더 함수를 직접 부르지 말고 `refresh(scope)` 를 사용.
4. 코드 블록을 정규식으로 지우지 말 것 — 앞뒤 문자열을 명시해 교체.
